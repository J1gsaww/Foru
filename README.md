# For u na 🌸

Visual Novel เล็ก ๆ บนมือถือ ทำเป็นของขวัญให้ใครคนหนึ่งได้พักใจ

เดินผ่านสวนลับยามเย็น พบกับตัวเองในวันวาน ตอบคำถามง่าย ๆ ระหว่างทาง
แล้วไปจบที่ริมทะเลสาบ กับประโยคที่อยากบอกมาตลอด — *ที่ผ่านมา เก่งมากแล้วนะ*

## เล่นยังไง

- เปิดบนมือถือ (จอแนวตั้ง) และเปิดเสียงไว้ด้วย
- แตะหน้าจอเพื่อไปต่อ แตะปุ่มเพื่อเลือกคำตอบ
- ปุ่ม ☰ มุมขวาบนใช้อ่านบทสนทนาย้อนหลัง ปุ่ม 🔊 ใช้ปิด/เปิดเสียง
- คำตอบที่เลือกระหว่างทาง จะกลับมาอีกครั้งในตอนจบ

## ฉากในเรื่อง

| # | ฉาก | ใครอยู่ในฉาก |
|---|-----|-------------|
| 0 | กระท่อมไม้กลางสวน | ไฮเดรนเยีย |
| 1 | ลานชิงช้าใต้ต้นไม้ใหญ่ | เด็กน้อยเรืองแสง |
| 2 | ร้านรองเท้าเจ้าสาวเล็ก ๆ | หญิงสาวเรืองแสงหลังเคาน์เตอร์ |
| 3 | ทะเลสาบ | เงาในน้ำ |
| 4 | ริมทะเลสาบ ข้างเปียโน | ทุกคน + แมวเปอร์เซียสีเทา |

## โครงสร้างไฟล์

```
index.html      หน้าเว็บ
style.css       หน้าตา เลย์เอาต์ และเอฟเฟกต์
scenes.js       รายการภาพแต่ละฉาก + สีพื้น + เอฟเฟกต์
story.js        บททั้งหมด (แก้คำพูดได้ที่นี่ที่เดียว)
engine.js       ตัวเล่นบท ตัวเลือก และเสียง
assets/web/     ภาพฉาก (webp ที่ย่อแล้ว)
assets/shoes/   ภาพรองเท้า 4 คู่
```

## รันในเครื่อง

ไม่ต้องติดตั้งอะไร เปิด `index.html` ด้วย VS Code Live Server หรือ

```
python -m http.server 5500
```

แล้วเข้า `http://localhost:5500`

ทดสอบข้ามไปฉากที่ต้องการได้ด้วย `?jump=garden` / `shop` / `lake` / `end`
